# Codex starter files

1. Create an empty private GitHub repository (for example `rpg-forge`).
2. Put `BUILD_PLAN.md`, `AGENTS.md`, and `START_CODEX.md` at the repository root.
3. Open the repository in Codex and paste the contents of `START_CODEX.md` as the first task, or ask Codex to execute that file.
4. Let Codex implement only the foundation sprint and check its actual test/build results.
5. Review the result before connecting a Cloudflare account or approving deployment.

The plan is intentionally incremental: it treats SRD ingestion and SRD mechanical implementation as separate, independently verifiable tasks. Source URLs are included in the build plan.
